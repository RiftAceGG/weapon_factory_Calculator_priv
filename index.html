      // 03 — Growth

      Pet level calculator

      Search for any pet, pick its variant, and set a level from 0 to 500 to see its boosted stats. Level 0 is the pet's base stats with no boost — the boost starts at level 1, adding a flat 1% to Money and Exp per level. Gems don't scale with level, same as they don't scale with variant. Pets that work off a percentage of your best card instead gain 0.05% per level. This all applies the same no matter which variant (Normal, Golden, Shiny, Rainbow, Void) the pet is.

    Connecting a server — what on-site chat and notifications need
    
      
      
      Trade listings that other people can see, chat between two players, and notifications all need one thing this
      site does not have: a server that stores messages and hands them to other browsers. A static page can't do it —
      your browser has no way to reach anyone else's.
      
      
      The quickest route is to skip the server entirely: run the trading in your Discord, and let this page
      build the posts. Discord already gives you accounts, DMs, notifications, moderation tools and a report button,
      and people are there anyway.
      
      
      If you do want it on the site, the hub is written so listings can come from an API instead of this
      device. Point it at your backend and the same UI reads from it:
      
      
      TradingHub.configureRemote({
  endpoint: 'https://your-server/api',
  headers:  { 'Authorization': 'Bearer …' }
});
      
      
      It expects GET {endpoint}/listings to return { listings: [ … ] } in the same shape
      as a saved listing here, and POST {endpoint}/listings to accept one. Anything beyond that — chat,
      notifications, accounts — is server work, not page work.
      
      
      Worth planning for before you open chat to strangers: a lot of Roblox players are children. If people
      can message each other on your site you become responsible for what gets said — you would want reporting,
      blocking, a way to remove posts, and someone actually reading reports. That is the real reason most fan sites
      hand messaging to Discord rather than building their own.
